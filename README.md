# Divyanshu Tiwari — Portfolio

My personal portfolio website, showcasing my projects, skills, and experience.

🔗 **Live:** [portfolio-hai-chi.vercel.app](https://portfolio-hai-chi.vercel.app/)

## Tech Stack

- Vite + TypeScript
- React
- Tailwind CSS
- Radix UI / shadcn components
- GSAP for animations

## Development

```sh
git clone https://github.com/Divyanshutiwari102/Portfolio.git
cd Portfolio
npm i
npm run dev
```

## Build

```sh
npm run build
```

## Deployment

Deployed on [Vercel](https://vercel.com/), auto-deploys on push to \main\.
